# ZEBAYSH — Made-to-Order Tailoring Website

A modern and responsive tailoring website developed for **ZEBAYSH**, a premium made-to-order clothing brand. The website showcases tailoring services, custom clothing options and an elegant user experience across all devices.

## 🌐 Live Demo

https://zebayshofficial.vercel.app/

---

## ✨ Features

- Modern and clean user interface
- Fully responsive design
- Made-to-order tailoring showcase
- Custom clothing services
- Elegant animations and smooth scrolling
- Mobile-friendly layout
- Fast loading performance
- SEO-friendly structure

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Design
- Vercel (Deployment)

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/zebaysh-tailoring-website.git
```

Navigate into the project

```bash
cd zebaysh-tailoring-website
```

Open the project

```
Open index.html in your browser
```
